# Sovereign Recovery Protocol (SRP) v2.4

This repository contains the specification, formal models, and reference implementation for the Sovereign Recovery Protocol (SRP) v2.4. SRP is a framework for high-assurance, zero-trust endpoint restoration using hardware DRTM and seL4.

## Key Artifacts
* **Specification:** docs/SRP_v2.4_Specification.md
* **TLA+ Model:** spec/SRP_v2_4.tla
* **Coq Proof:** proof/SRP_v2_4.v
* **Reference Implementation:** src/main.rs
